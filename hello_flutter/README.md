# Hello Flutter

A simple "Hello World" Flutter starter application demonstrating the default counter app.

## Features

- Material Design 3 UI
- Stateful widget with a tap counter
- Flutter best practices and project layout

## Getting Started

1. Make sure [Flutter](https://flutter.dev/docs/get-started/install) is installed.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

## Running Tests

```bash
flutter test
```

## Project Structure

```
hello_flutter/
├── lib/
│   └── main.dart        # App entry point and UI
├── test/
│   └── widget_test.dart # Widget tests
└── pubspec.yaml         # Project configuration and dependencies
```
